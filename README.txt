WEBZOO - PROJETO FRONT-END

COMO ABRIR NO VS CODE
1. Extraia o arquivo ZIP para uma pasta do computador.
2. Abra o VS Code.
3. Clique em Arquivo > Abrir Pasta e selecione WebZoo_Nome_Sobrenome.
4. Abra o arquivo index.html.
5. Para visualizar, clique com o botão direito em index.html e escolha "Open with Live Server" (se a extensão Live Server estiver instalada). Também é possível abrir o index.html diretamente no navegador.

ESTRUTURA
index.html       Página inicial
animais.html     Fichas dos animais e filtros
visite.html      Horários, ingressos e consulta de clima
participe.html   Programas e formulário demonstrativo
css/style.css    Identidade visual e responsividade
js/              Interações e integração com APIs
assets/imagens/  Logo e imagens fornecidas para a atividade

FUNCIONALIDADES
- Menu responsivo para celular.
- Filtros por classe, alimentação e bioma na página Animais.
- Consulta de CEP usando a API pública ViaCEP.
- Consulta meteorológica usando a API Open-Meteo, para as coordenadas aproximadas informadas no material (Zoológico de São Paulo).
- Validação do formulário demonstrativo. Ele não envia nem armazena dados.
- Botão para voltar ao topo.
- Navegação entre as quatro páginas.

OBSERVAÇÕES IMPORTANTES
- Horários, valores de ingressos, telefone e e-mail são fictícios conforme o texto de apoio da atividade.
- O formulário é apenas demonstrativo e não coleta dados reais.
- As APIs precisam de conexão com a internet. Se não carregarem, verifique a conexão e tente novamente.
- O conteúdo e as imagens dos animais foram organizados a partir dos materiais enviados para a atividade.
- Antes de entregar, substitua no rodapé a identificação genérica da equipe pelos nomes exigidos pelo professor, se necessário.
